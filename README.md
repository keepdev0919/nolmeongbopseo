## 왜 만들었나

처음엔 **제주 설화를 바탕으로 한 여행 앱**을 졸업 프로젝트로 만들었어요. 이 아이디어로 **2026 관광데이터 활용 공모전** 예비심사를 통과하면서 진짜 서비스로 키우게 됐습니다.

그런데 서비스로 다시 보니, 졸업 프로젝트 때 기능을 채우기 급해서 설화를 억지로 넣은 부분이 많았어요. 그래서 질문을 바꿨습니다.

> 관광지에 도착한 사람은 **"여기서 뭘 보고 뭘 해야 하지?"**가 궁금하다.

그 답으로, 관광지를 **보고 나오는 곳이 아니라 플레이하고 나오는 곳**으로 바꿨어요.

## 어떻게 플레이하나

```
본다 → 발견한다 → 의미를 안다 → 다음 장소로 → CLEAR
```

- 관광지에 도착해 앱을 켜면 **플레이어**가 돼요.
- 실제 장소를 돌아다니며 지점을 찾고 **미션**을 풀어요.
- 직접 발견한 것의 의미를 알게 되고, 마지막엔 그 장소를 **CLEAR**합니다.
- 전문 가이드 없이 다니는 개인 · 소규모 여행자가 대상이에요. 가이드가 가리키며 설명하던 흐름을 **게임의 진행**으로 바꿨습니다.
