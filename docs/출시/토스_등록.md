## 2. 상세 설명 (500자 제한 — 373자)

놀멍봅서는 제주 관광지에 도착하는 순간 그곳을 게임판으로 바꿔 주는 여행 앱이에요. 관광지를 보고 나오지 말고, 플레이하고 나오세요.

퀘스트를 수락하면 안내 캐릭터 곱딱이가 길을 알려 줘요. 지점에 도착하면 눈앞의 실물을 살펴보고 미션의 답을 현장에서 직접 찾아요. 찾아낸 것이 무엇이었는지는 곱딱이가 목소리로 들려줘요(AI 음성). 힌트와 건너뛰기가 있고, 중간에 나가도 완료한 지점까지 저장돼요.

코스 탭에서는 제주 여행자들이 직접 짠 코스 6천여 건에서 권역과 기간에 맞는 길을 찾아 드려요. 장소를 누르면 운영시간, 주차, 주변 화장실과 버스정류장까지 한 화면에서 볼 수 있어요.

로그인 없이 바로 시작하고, 위치 권한 없이도 끝까지 플레이할 수 있어요.
