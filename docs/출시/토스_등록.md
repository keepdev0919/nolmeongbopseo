## 6. 핵심 지표 (2026-09-29 준비)

토스 추천·노출의 기준이다. 콘솔 웹 「핵심 지표」에서만 설정할 수 있다(MCP 에는 설정 도구가 없다).
이벤트는 `miniapp/src/lib/analytics.ts` — **이름을 바꾸면 지표가 끊긴다.**

| 지표 | 조건 | 이벤트 |
|---|---|---|
| 활성 (1개) | 퀘스트를 시작하거나 코스를 찾아본 사용자 | `play_start` OR `/course/list::screen` |
| 전환 — 대표 | PLAY 를 CLEAR 한 사용자 | `play_clear` |
| 전환 — 보조 | 퀘스트를 시작한 사용자 | `play_start` |
| 전환 — 보조 | 코스를 담은 사용자 | `course_save` |

- 화면 이동(`/course::screen` 등)은 토스가 자동 기록한다. CLEAR 는 주소가 안 바뀌어 직접 보낸다.
- 새 이벤트는 이 이벤트가 든 번들이 출시되고 한 번 이상 발생해야 콘솔 이벤트 목록에 나타난다.
